## 🚀 Overview

**MyFolio** solves developer portfolio fatigue. Traditional portfolio builders trap engineers in rigid, cookie-cutter templates with repetitive purple gradients, bloated dependencies, and proprietary platform lock-in. MyFolio introduces an **Autonomous, Content-First Generative Architecture**:

1. **Strict Zero Predefined Template Filling**: Understands WHO the candidate is first. The engine ingests the developer's real git history, pull requests, commit patterns, and project architectures to dynamically structure a tailored Information Architecture (IA) model.
2. **Authentic Spatial 3D Worlds**: Interactive Three.js WebGL viewports, procedural lighting, materials, and physics-driven cards tailored to the developer's actual discipline (Distributed Systems, Autonomous AI, Web3/Cryptographic Consensus, Robotics/Embedded, Design Engineering).
3. **Strict Zero Vendor Lock-In**: Full standalone source code export (HTML5, CSS3, ES6 JavaScript, WebGL assets, fonts) in a clean ZIP download. Developers own their code permanently and can self-host anywhere (Netlify, Vercel, Cloudflare Pages, GitHub Pages, or private VPS).
4. **Autonomous Emerging Agent Protocols (AEO Native)**: Fully optimized for autonomous AI search engines (ChatGPT, Claude, Perplexity, Gemini, Applebot) with native Markdown content negotiation, RFC 9309 API catalog, A2A Agent Card, WebMCP in-browser tools, and RFC 9728 OAuth discovery.
5. **Dynamic Section Morphing**: Every section exists only if backed by verifiable proof. If evidence does not exist, the section is omitted gracefully without leaking dummy placeholder text.

## 🛡️ Enterprise Security & Technical Policies

- **Strict Zero Port 3000 Policy**: Under NO circumstances is port 3000 bound, tested, or configured. Dev and production servers strictly run on `PORT=5050` (or dynamic fallbacks `5051+`, `10000+`).
- **Scrypt Password Hashing**: Cryptographically salted passwords with high-entropy peppers.
- **SSRF & Network Boundary Immunity**: Strict private CIDR blocking (`10.0.0.0/8`, `127.0.0.0/8`, `169.254.169.254`) on all remote scraping inputs.
- **Honeypot Bot Defense**: Silent honeypot trap fields preventing malicious automated scraping.
- **Origin-Isolated Previews**: Sandboxed iframe previews (`/p/:siteId`) preventing script escalation into admin context.
- **Search Engine Optimization (SEO & GEO)**:
  - Canonical URL synchronization (`https://myfolio.tech`).
  - Google Search Console direct verification pass-through (`/google001961baa3b6a214.html`).
  - Single `<h1>` per page with semantic hierarchy across all routes.
  - JSON-LD Structured Data (`SoftwareApplication`, `FAQPage`, `Organization`, `BreadcrumbList`).
  - RFC 8288 HTTP `Link` headers pointing crawlers to `llms.txt`, `api-catalog`, and `agent-card`.

## 🚀 Quick Start & Local Development

### Prerequisites
* **Node.js 20+ LTS** (Node 20 or 22 recommended)
* **npm 10+**

### 1. Clone & Install
```bash
git clone https://github.com/Abdul-Aziz-Nooruddin/myfolio.tech.git
cd myfolio-platform
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env
```
Ensure your `.env` contains:
```env
PORT=5050
GEMINI_API_KEY=your_gemini_api_key
SUPABASE_URL=your_supabase_url
SUPABASE_SERVICE_ROLE_KEY=your_supabase_key
```

### 3. Launch Development Server
```bash
npm run dev
```
Open **[http://localhost:5050](http://localhost:5050)** in your browser.
