## 1. The Architecture: Ingesting GitHub Without Hallucinations

The first major challenge in building an **[AI portfolio generator](https://myfolio.tech/ai-portfolio-generator)** is avoiding AI hallucinations. Generic LLM wrappers tend to invent metrics, fake previous employers, or create fictional tech stacks.

In MyFolio, we implemented a strict evidence-grounded ingestion pipeline:

```
[Public GitHub Handle]
         ↓
[Octokit GitHub API Ingestion]
  ├── Commit history & recency
  ├── Language distribution ratios
  ├── Root & subfolder README.md parsing
  └── Package manifests (package.json, Cargo.toml, go.mod, pyproject.toml)
         ↓
[Deterministic Technology Classifier]
  ├── Frontend: React, Vue, Svelte, Next.js, Three.js
  ├── Backend: Node.js, Go, Rust, Python, FastAPI, Spring
  └── Web3 / Systems: Solidity, Algorand Python, EVM, Docker, Kubernetes
         ↓
[Technical Case Study Synthesizer]
  ├── Authentic Problem Statement
  ├── Architecture & Data Flow
  ├── Real Technical Challenges Solved
  └── Direct GitHub Commit & Live Demo References
```

Every single project card generated by MyFolio represents an authentic technical case study backed by real repository commits. If a repository has no documentation, the engine gracefully analyzes commit summaries and source manifests rather than fabricating claims.

## 2. Real-Time Spatial 3D: Running WebGL at 60 FPS

A major criticism of 3D portfolio websites is that they are often sluggish, battery-draining, and unresponsive. To ensure buttery smooth 60–120 FPS performance across all devices, MyFolio incorporates an authoritative spatial pipeline:

### A. Lenis Inertia Scrolling Synchronized with GSAP
Instead of native browser jerky scroll jumps, we mounted **`lenis`** smooth inertia scrolling synchronized with `gsap.ticker`. This allows continuous camera rotation, Z-depth spatial fly-throughs, and section pinning without frame drops.

### B. Viewport Culling & Procedural Shaders
Off-screen Three.js meshes and particle systems are aggressively culled using `IntersectionObserver`. When a user navigates between sections, render loops for off-screen canvases are immediately paused, keeping GPU memory consumption under 45 MB.

### C. Reduced Motion First Class Citizen
Accessibility is non-negotiable. Every template strictly respects `prefers-reduced-motion: reduce` by halting WebGL canvas rotations, collapsing 3D depth into clean 2D spatial layouts, and disabling inertial wheel smoothing.
