Frequently Asked Questions

Have questions about using our portfolio maker?

Can I use this portfolio maker for free?

Yes! You get 3 free evaluation builds every week on the Free Starter plan. Test designs, customize in Web Studio, and view full 3D interactive sandboxes with no credit card required.

Can I customize text, projects, and colors?

Yes, absolutely. MyFolio includes Web Studio, an interactive visual customizer where you can edit project titles, descriptions, live demo links, skill badges, and 3D visual universes in real time.

What format is the exported code in?

You receive a clean, production-ready ZIP archive containing HTML5, compiled CSS, JavaScript, WebGL shaders, fonts, and assets. It can be uploaded directly to GitHub Pages, Netlify, Vercel, or AWS S3.

How is this developer portfolio maker different from Wix or Squarespace?

Wix and Squarespace are closed proprietary website builders with recurring monthly subscriptions that hold your site hostage. MyFolio is built for developers: it ingests GitHub code, renders interactive 3D WebGL scenes, and provides full standalone source code ZIP download.

Does this portfolio maker support mobile touch tilt and gyroscope physics?

Yes. Every 3D WebGL universe includes responsive touch-driven camera controls and mobile gyroscope tilt that responds to device orientation, with battery-saving frame throttling.

What are the performance metrics of the generated portfolio?

Portfolios achieve sub-50ms First Contentful Paint (FCP) and 0 Cumulative Layout Shift (CLS), with full prefers-reduced-motion accessibility fallbacks for users with motion sensitivities.
