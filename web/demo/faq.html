Frequently Asked Questions

Everything you need to know about MyFolio, source code exports, and custom domains.

What does "Full Source Code Export" actually include?

When you download your portfolio ZIP, you get 100% clean, standalone HTML, CSS, JavaScript files, and 3D assets. There are no obfuscated bundles, no mandatory Node.js runtime, and zero external proprietary dependencies. You can double-click `index.html` on your desktop or push directly to GitHub Pages.

Can I host my portfolio on Vercel, Netlify, or AWS?

Yes. Because every exported website is built on standard web technologies, you can deploy your exported folder to Vercel, Netlify, Cloudflare Pages, AWS S3, or any basic Apache/Nginx web server with zero configuration.

How does custom domain mapping work?

If you prefer MyFolio to handle high-speed global hosting, simply enter your custom domain (like `jane.dev`) in the Dashboard and add the two DNS records provided. We automatically provision an SSL certificate and serve your portfolio via global Cloudflare edge caching.

Are there any recurring monthly charges?

No. MyFolio operates on a transparent, developer-friendly one-time license. Once unlocked for ₹149, your portfolio is yours forever with unlimited revisions and free downloads.
