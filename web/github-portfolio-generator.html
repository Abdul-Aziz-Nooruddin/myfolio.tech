MyFolio inspects your public GitHub account via the GitHub API, analyzes your most prominent repositories, extracts technologies and descriptions, and renders an interactive 3D WebGL website showcasing your projects with live links.

Yes, 100%. Every paid portfolio on MyFolio comes with a complete source code ZIP download. You own the HTML, CSS, JavaScript, WebGL shaders, and 3D assets completely with zero vendor lock-in.
